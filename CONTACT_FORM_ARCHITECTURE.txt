                        ERROR HANDLING FLOW

    Form Submission
          │
          ├──▶ Try localStorage save
          │         │
          │         ├─▶ Success ✓
          │         │
          │         └─▶ Fail ✗ → Log warning, continue
          │
          ├──▶ Try API call (/api/send-email)
          │         │
          │         ├─▶ Success ✓
          │         │      │
          │         │      ├─▶ KV Storage ✓
          │         │      │
          │         │      └─▶ Email Send ✓
          │         │             │
          │         │             └─▶ Show success message
          │         │
          │         └─▶ Fail ✗
          │                │
          │                ├─▶ Network error
          │                │      └─▶ Show warning: "Saved locally"
          │                │
          │                └─▶ Server error
          │                       └─▶ Show warning: "Pending delivery"
          │
          └──▶ Result: Message NEVER lost!
                      ✓ In localStorage
                      ✓ User notified
                      ✓ Can retry later
